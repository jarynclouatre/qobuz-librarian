Library maintenance

A normal library scan picks up changes in your folders. To check Qobuz for new releases, use Check new releases on the Library page. Use a full rescan only after large manual changes to your files. It ignores the unchanged-folder cache and re-reads every artist, so it takes as long as a first scan.
