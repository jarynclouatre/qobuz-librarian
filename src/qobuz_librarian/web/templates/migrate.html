Migration needs a source and destination path set in the configuration file.

Source path (MIGRATE_SRC)
The existing library to organise, as a path inside the container, e.g. /migrate-source.
Destination path (MIGRATE_DEST)
An empty folder for the organised copy, inside the container, e.g. /migrate-dest.
  1. 1 Mount both folders in the container's Compose file, as in Existing libraries.
  2. 2 Set MIGRATE_SRC and MIGRATE_DEST to those folders in .env or Compose.
  3. 3 Recreate the service with docker compose up -d, then return to this page.
